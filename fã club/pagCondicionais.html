Resumo

As estruturas condicionais são ferramentas que permitem ao seu código tomar decisões sozinho. Elas funcionam como bifurcações em uma estrada: o programa analisa uma condição e decide qual caminho seguir.

Exemplo 01

Imagine que estamos programando o sistema de um carro autônomo. Ele precisa ler a cor do semáforo e decidir o que fazer.

Entendendo o código passo a passo

if (Se)
É a primeira tentativa. O programa pergunta: "A cor é verde?". Se for, ele executa o que está nos primeiros colchetes e ignora o resto.
else if (Senão se)
Se a primeira pergunta der falso, ele tenta esta segunda opção: "Bem, se não é verde, será que é amarelo?"
else (Senão / Caso contrário)
É o seu plano de segurança. Se o sinal não for verde e não for amarelo (ou seja, se for vermelho ou se faltar energia), o programa cai direto aqui e manda parar.

Exemplo 02

Imagine que estamos programando o sistema de um carro autônomo. Ele precisa ler o nível da bateria e decidir o que fazer.

Entendendo o código passo a passo

if
Testa se a bateria está exatamente em 100%. Se estiver, avisa para tirar do carregador.
else if
Só é executado se a primeira condição for falsa. Ele checa se a carga está em 20% ou menos, alertando para ativar a economia.
else
Funciona como uma "saída padrão". Se a bateria não estiver cheia e nem fraca (ou seja, estiver entre 21% e 99%), ele roda a mensagem de uso normal.

Agora vamos aos testes!

Teste o Exemplo 01



function testarSemaforo() {
    var cor = document.getElementById("corSemaforo").value;

    if (cor == "verde") {
        alert("Pode seguir!");
    } else if (cor == "amarelo") {
        alert("Atenção, reduza a velocidade!");
    } else {
        alert("Pare o carro!");
    }
}

Teste o Exemplo 02



function testarBateria() {
    var bateria = document.getElementById("nivelBateria").value;

    if (bateria == 100) {
        alert("Bateria cheia, tire do carregador.");
    } else if (bateria <= 20) {
        alert("Bateria fraca, ativando economia.");
    } else {
        alert("Uso normal do Smartphone.");
    }
}

Atividade 01

Uma sala de cinema oferece desconto na entrada de acordo com a idade do cliente. Escreva um programa em JavaScript que defina uma variável idade. Se a idade for menor que 18 anos, o programa deve exibir a mensagem: "Você tem direito ao ingresso promocional!" Caso contrário (se tiver 18 anos ou mais), deve exibir: "Você deve pagar o valor integral do ingresso.".

Teste a Atividade 01



function testarIdade() {
    var idade = document.getElementById("idadeCliente").value;

    if (idade < 18) {
        alert("Você tem direito ao ingresso promocional!");
    } else {
        alert("Você deve pagar o valor integral do ingresso.");
    }
}

Atividade 02

Uma loja de roupas oferece desconto de acordo com o valor total da compra do cliente. Escreva um programa em JavaScript que defina uma variável valorCompra. Se o valor da compra for maior ou igual a R$ 200, o programa deve exibir a mensagem: "Você ganhou 20% de desconto!" Se o valor for maior ou igual a R$ 100 (mas menor que R$ 200), deve exibir: "Você ganhou 10% de desconto!" Caso contrário (valor abaixo de R$ 100), deve exibir: "Sua compra não tem desconto."

Teste a Atividade 02



function testarDesconto() {
    var valorCompra = document.getElementById("valorCompra").value;

    if (valorCompra >= 200) {
        alert("Você ganhou 20% de desconto!");
    } else if (valorCompra >= 100) {
        alert("Você ganhou 10% de desconto!");
    } else {
        alert("Sua compra não tem desconto.");
    }
}
