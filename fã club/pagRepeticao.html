Resumo

As estruturas de repetição são ferramentas que permitem ao seu código executar um mesmo bloco de instruções várias vezes, sem precisar reescrevê-lo. Elas funcionam como um "loop": o programa repete uma ação enquanto uma condição for verdadeira ou até que um número definido de repetições seja atingido.

Exemplo 01

Imagine que estamos programando o sistema de controle de estoque da loja. Ele precisa verificar, um por um, cada produto guardado no depósito.

Entendendo o código passo a passo

Inicialização (var i = 1)
É o ponto de partida do laço. Aqui criamos uma variável contadora que começa em 1, representando o primeiro produto.
Condição (i <= total)
Antes de cada repetição, o programa pergunta: "Ainda existem produtos para verificar?". Enquanto a resposta for verdadeira, o laço continua.
Incremento (i++)
Depois de cada repetição, o contador aumenta em 1. É o que garante que o laço vá avançando produto por produto, até não sobrar nenhum.

Exemplo 02

Imagine agora que estamos simulando o carregamento de uma bateria. O sistema precisa repetir o processo de carregar até que ela chegue a 100%.

Entendendo o código passo a passo

while
Testa a condição antes de cada repetição. Enquanto a carga da bateria for menor que 100%, o laço continua rodando.
Corpo do laço
A cada repetição, a carga da bateria aumenta um pouco (por exemplo, 10%), simulando o processo de carregamento.
Fim do laço
Assim que a condição se torna falsa (a bateria chega a 100% ou mais), o programa para de repetir e segue para a próxima instrução.

Agora vamos aos testes!

Teste o Exemplo 01



function testarEstoque() {
    var total = document.getElementById("totalProdutos").value;
    var mensagem = "";

    for (var i = 1; i <= total; i++) {
        mensagem = mensagem + "Verificando produto " + i + "\n";
    }

    alert(mensagem);
}

Teste o Exemplo 02



function testarCarregamento() {
    var carga = document.getElementById("cargaInicial").value;
    var mensagem = "";

    while (carga < 100) {
        carga = carga + 10;
        mensagem = mensagem + "Carregando... " + carga + "%\n";
    }

    mensagem = mensagem + "Bateria totalmente carregada!";

    alert(mensagem);
}

Atividade 01

Uma loja quer exibir a tabuada de um produto vendido em caixas, para ajudar o cliente a calcular quantas unidades tem em várias caixas. Escreva um programa em JavaScript que use um laço for para exibir a tabuada (de 1 a 10) de um número informado pelo cliente.

Teste a Atividade 01



function testarTabuada() {
    var numero = document.getElementById("numeroTabuada").value;
    var mensagem = "";

    for (var i = 1; i <= 10; i++) {
        mensagem = mensagem + numero + " x " + i + " = " + (numero * i) + "\n";
    }

    alert(mensagem);
}

Atividade 02

O caixa da loja precisa somar o valor de vários produtos idênticos comprados por um cliente, um de cada vez, até que a quantidade desejada seja atingida. Escreva um programa em JavaScript que use um laço while para calcular a soma de um valor unitário repetido uma certa quantidade de vezes.

Teste a Atividade 02





function testarSomaCompra() {
    var valorUnitario = document.getElementById("valorUnitario").value;
    var quantidade = document.getElementById("quantidadeItens").value;
    var total = 0;
    var contador = 0;

    while (contador < quantidade) {
        total = total + valorUnitario;
        contador = contador + 1;
    }

    alert("Total final da compra: R$ " + total);
}
