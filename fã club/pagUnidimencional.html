Resumo

Vetores (arrays) unidimensionais são estruturas que permitem armazenar vários valores em uma única variável, organizados em posições (índices) que começam do zero. Eles funcionam como uma prateleira numerada: cada posição guarda um item, e podemos acessar, percorrer ou modificar qualquer um deles usando seu número de posição.

Exemplo 01

Imagine que estamos programando o sistema de vendas da loja. Ele precisa somar o valor de todos os produtos guardados em um vetor de preços.

Entendendo o código passo a passo

Declaração do vetor
Criamos uma variável que guarda vários valores ao mesmo tempo, como var precos = [50, 120, 35, 80];. Cada valor fica em uma posição (índice), começando em 0.
Percorrendo o vetor (for)
Usamos um laço for para visitar cada posição do vetor, do índice 0 até o último (precos.length - 1), acessando cada valor com precos[i].
Acumulando o resultado
A cada volta do laço, somamos o valor da posição atual a uma variável total, até percorrer todo o vetor.

Exemplo 02

Imagine agora que estamos verificando o estoque de baterias e queremos descobrir qual delas tem a maior carga registrada em um vetor.

Entendendo o código passo a passo

Valor inicial
Começamos assumindo que o maior valor é o primeiro item do vetor (cargas[0]).
Comparação a cada posição
Percorremos o vetor com um laço, comparando cada posição com o maior valor encontrado até o momento.
Atualização do maior valor
Sempre que encontramos um valor maior que o atual "maior", atualizamos a variável. Ao final do laço, ela contém o maior valor do vetor.

Teste o Exemplo 01



function testarSomaVetor() {
    var texto = document.getElementById("precosProdutos").value;
    var precos = texto.split(",").map(Number);
    var total = 0;
    var mensagem = "";

    for (var i = 0; i < precos.length; i++) {
        total += precos[i];
        mensagem += "Produto " + i + ": R$ " + precos[i] + "
";
    }

    mensagem += "Total da venda: R$ " + total;

    document.getElementById("resultadoSomaVetor").innerHTML = mensagem;
}

Teste o Exemplo 02



function testarMaiorCarga() {
    var texto = document.getElementById("cargasBaterias").value;
    var cargas = texto.split(",").map(Number);
    var maior = cargas[0];

    for (var i = 1; i < cargas.length; i++) {
        if (cargas[i] > maior) {
            maior = cargas[i];
        }
    }

    document.getElementById("resultadoMaiorCarga").innerHTML = "A maior carga encontrada foi: " + maior + "%";
}

Atividade 01

Uma loja quer calcular a média de avaliação de um produto, com base nas notas dadas pelos clientes. Escreva um programa em JavaScript que armazene as notas em um vetor e use um laço for para calcular a média dos valores.

Teste a Atividade 01



function testarMediaNotas() {
    var texto = document.getElementById("notasAvaliacao").value;
    var notas = texto.split(",").map(Number);
    var soma = 0;

    for (var i = 0; i < notas.length; i++) {
        soma += notas[i];
    }

    var media = soma / notas.length;

    document.getElementById("resultadoMediaNotas").innerHTML = "A média das notas é: " + media.toFixed(2);
}

Atividade 02

O sistema da loja precisa verificar se um determinado produto está disponível em um vetor de códigos de estoque. Escreva um programa em JavaScript que percorra um vetor de códigos e verifique se um código informado pelo cliente está presente, contando também quantas vezes ele aparece.

Teste a Atividade 02





function testarBuscaCodigo() {
    var texto = document.getElementById("codigosEstoque").value;
    var codigos = texto.split(",").map(Number);
    var busca = parseInt(document.getElementById("codigoBusca").value);
    var contador = 0;

    for (var i = 0; i < codigos.length; i++) {
        if (codigos[i] === busca) {
            contador++;
        }
    }

    var mensagem = "";
    if (contador > 0) {
        mensagem = "O código " + busca + " foi encontrado " + contador + " vez(es) no estoque.";
    } else {
        mensagem = "O código " + busca + " não foi encontrado no estoque.";
    }

    document.getElementById("resultadoBuscaCodigo").innerHTML = mensagem;
}
